# Pupilo 17 · Variante Karpov

Lecciones 33–42 del estudio «Caro Kann al estilo Pupilochess» (variante Karpov, 4...Cd7), con el mismo entrenador del Método PC1 del repo `chess`.

- Cada variante del maestro es una línea propia que empieza en la posición inicial (253 líneas).
- Los comentarios, flechas y casillas del maestro se muestran tal cual, jugada a jugada.

Web: https://la86926.github.io/pupilo17/

Para regenerar los datos desde los PGN: `python3 tools/extraer.py pgn/estudio-33-42.pgn lecciones-data.js` (requiere `pip install chess`).
